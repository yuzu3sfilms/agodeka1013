# AI橋本新 v10.3 style and search fix

## 修正理由

v10.2で以下の問題が出た。

### 1. 普通の文章から変な検索が走る

```text
received: お前は遅れるから早く来い。
dynamic_search terms=['お前は遅れるから早く来い', ...]
...
reply: 世紀の一戦、ニッパーは絶対に要るね！
```

これは、文章全体から雑なn-gramを作って全文検索していたせい。
無理やりヒットして、関係ないニッパー/ガンプラ文脈に飛んだ。

### 2. 口調がAIっぽい

```text
ニッパーはガンプラの組み立てに使うんだよね、痛そうだから気を付けて使うよ
ガンプラは、昔のプロポーションが好きだから、今も作ってます！
```

これは説明AIの返答。
橋本新っぽくない。

## v10.3の修正

### 1. 雑な全文n-gram検索を廃止

ユーザー発言から抽出する検索語を以下中心に絞った。

```text
固有名詞
カタカナ語
英数字語
漢字語
critical term（顎/ムタ/牛角など）
```

普通の文章断片は検索語にしない。

そのため、

```text
お前は遅れるから早く来い。
```

のような発言は、明確な固有語がなければ無視されやすくなる。

### 2. 口調サンプルを毎回渡す

検索で拾ったエピソード内の橋本新系発言を、口調サンプルとしてGroqに渡す。

```text
口調サンプル:
- ...
- ...
```

### 3. 説明AI禁止を強化

禁止したもの:

```text
〜だよね
〜なんだよね
〜します
〜ます！
気を付けて
一般知識の説明
ChatGPT風のまとめ
```

### 4. 生成後にAIっぽい語尾を軽く補正

例:

```text
作ってます！ → 作ってるわ
気を付けて使うよ → 使うやつ
```

## ログ

```text
dynamic_search terms=[...] hits=... episodes=... called=...
groq_raw: ...
generation path: groq_dynamic_episode
reply: ...
```

## 挙動

```text
エピソードあり
→ 過去ログエピソード + 口調サンプルを元に返答

エピソードなし + 呼びかけあり
→ ｷｬﾋﾟｨ

エピソードなし + 呼びかけなし
→ 無視

Groqエラー/429
→ ｷｬﾋﾟｨ
```
