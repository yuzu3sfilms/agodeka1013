# AI橋本新 v11.1 predicate fuzzy search

## 修正理由

v11では、固有名詞・名詞系の検索は改善したが、述語系が完全一致に寄りすぎていた。

例:

```text
遅れる
遅れた
遅刻
遅い

使う
使った
使って
用途

作ってる
作る
作った
組み立て
```

このへんが完全一致しないと漏れやすかった。

## v11.1の修正

### 1. 検索語を2系統に分けた

```text
terms      = 固有名詞・名詞・カタカナ・漢字語
predicates = 述語・活用・語幹・言い換え
```

ログ:

```text
dynamic_search terms=[...] predicates=[...] hits=... episodes=... called=... question=...
```

### 2. 述語展開を追加

例:

```text
遅れる → 遅れ / 遅刻 / 遅い / 遅れて / 遅れた
来い → 来い / 来て / 来る / 来た / 集合
使う → 使う / 使った / 使って / 用途 / 何に使
作ってる → 作る / 作った / 作って / 組み立て
欲しい → 欲しい / ほしい / 欲し / いる / 要る
```

### 3. 雑な全文n-gramは復活させない

v10.2の失敗だった、

```text
お前は遅れるから早く来い
→ お前は遅れるから早く来い / 遅れるから早く来 / ...
```

のような文章断片検索はしない。

述語は別枠で低めの重みで検索する。

### 4. ヒット表示

`matched` の中で `*` がついているものは述語展開でヒットした語。

例:

```text
matched: 遅れ*, 遅刻*
```
